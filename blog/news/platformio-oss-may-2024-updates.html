PlatformIO Open Source May Updates

PlatformIO Core bugfix release, New boards and dev-kits, Updates for Espressif32, ST STM32, Microchip SAM, Nordic nRF52 and mbed-enabled dev-platforms

Valerii Koval
Head of System Integration at PlatformIO Labs
Share:

Welcome to the May 2024 updates of PlatformIO Open Source professional collaborative platform for embedded development. This month we received a lot of helpful feedback from our community, which let us identify the most important parts of our OSS ecosystem that required our attention, so there are plenty of updates pushed in this month that we hope you will like.

During May, we rolled out a bugfix release for PlatformIO Core, added support for the new Arduino ESP32 core v2.0.16, rolled out updates for several popular development platforms, fixed a lot of issues. Some of the key highlights include:

  • PlatformIO Core v6.1.15
  • Espressif32 dev-platform v6.7
  • ST STM32 dev-platform v17.4
  • Nordic nRF52 dev-platform v10.5
  • Microchip SAM dev-platform v8.3
  • Arduino Core for mbed-enabled devices v4.1.3

PlatformIO Core v6.1.15

PlatformIO Core is the heart of the whole PlatformIO ecosystem and we are excited to announce the next maintenance release with bugfixes:

  • Resolved an issue where the LDF couldn’t locate a library dependency declared via version control system repository (issue #4885)
  • Resolved an issue related to the inaccurate detection of the Clang compiler (pull #4897)

See Release Notes for more detailed information and use pio upgrade command to update to the latest version.

Espressif32 dev-platform v6.7

The new release of the Espressif 32 dev-platform brings support for the latest Arduino core, new boards and dev-kits, several fixes and improvements:

  • New boards: ESP32-S3 PowerFeather, MotorGo Mini 1, senseBox MCU-S2
  • Added support for Arduino v2.0.16 (release notes)
  • Updated toolchain packages for IDF integration to v13.2.0 (#1360)
  • Improvements to esp32_exception_decoder (#1357)
  • Better handling of IDF linker script fragments
  • Minor fixes and improvements

Related resources for the Espressif32 dev-platform:

  • Documentation
  • Project Examples

ST STM32 dev-platform v17.4

The new release of the ST STM32 dev-platform v17.4 brings support for the latest Arduino-mbed core and several bug fixes:

  • Updated Arduino-mbed core to v4.1.3 (release notes)
  • Added consistent set of STM32xx defines to all boards (#760)
  • Added Arduino support for Nucleo-F446ZE board (#772, #773)
  • Fixed ST STM32G0316-DISCO flash size (#767)

Related resources for the ST STM32 dev-platform:

  • Documentation
  • Project Examples

Nordic nRF52 dev-platform v10.5

The new release of the Nordic nRF52 dev-platform v10.5 comes with updated Arduino cores:

  • Updated Adafruit Core to the latest v1.6.1 (release notes)
  • Updated Arduino-mbed core to v4.1.3 (release notes)

Related resources for the Nordic nRF52 dev-platform:

  • Documentation
  • Project Examples

Microchip SAM dev-platform v8.3

The new release of the Microchip SAM dev-platform brings updates for several popular Arduino cores:

  • Updated Arduino Core to v1.8.14 (release notes)
  • Updated Adafruit Core to v1.7.16 (release notes)
  • Updated Seeed Core to v1.8.5 (release notes)

Related resources for the Microchip SAM dev-platform:

  • Documentation
  • Project Examples

Arduino Core for mbed-enabled devices v4.1.3

The ST STM32, Nordic nRF52 and Raspberry Pi RP2040 dev-platforms have been updated to support the latest Arduino Core for mbed-enabled devices v4.1.3. According to the release notes, v4.1.3 brings a lot of bugfixes and improvements in the core and accompanying libraries.
